# skema-halle

Native Hülle der Hallen-App des SLSHM für das Hallen-iPad: zeigt die Web-App am iPad als Regie
und am TV über Apples Szene für externe Displays als Bühne. Ausbau der Probe S1-H
(`alexandercarreira-arch/skema-buehnenprobe`). Die Web-App selbst liegt in einem privaten Repo;
hier steht nur der native Teil und sein Bau-Ablauf auf einem macOS-Runner von GitHub.

Bauzettel: im privaten Repo unter `docs/plan/50-bauzettel-huelle.md`.
